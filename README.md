# EE142_Final_Project: Auto-Encoding Variational Bayes

## Overview

We reproduced some theories for Auto-Encoding Variational Bayes, discussed some differences between it acted upon Auto-Encoding Variational Bayes and Denoising Diffusion Probabilistic Models, conducted experiments on the `MNIST` dataset and analyzed some results and its related reasons.

---

## File Descriptions

### 1. `vae_model.py`
- This file implements a simple Variational Autoencoder (VAE) model.
- The model is built using fundamental components (e.g. Linear Layers), focusing on the basics of variational inference.

### 2. `train.py`
- A script for training and testing the VAE model.
- Includes experiments and visualizations of results generated from the trained VAE.
- **How to run:** Ensure you have the necessary Python environment set up, and execute this file to replicate the experiments.

### 3. `Final_Report.pdf`
- The final report for the project, detailing the methodology, experiments, and results.


## Prerequisites

To run the code in this project, ensure you have the following installed:
- Python (3.x)
- Essential libraries such as NumPy, PyTorch, Matplotlib, etc.
